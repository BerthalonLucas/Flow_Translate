# Icons

Les 30 icônes du système, copiées depuis `lucide-react` 1.43.0 (licence ISC, notices MIT des icônes issues de Feather), grille 24, trait 1,75, extrémités et jointures arrondies. Encre `#16171b` dans ces fichiers pour l’affichage en `<img>` ; dans le code, le trait est `currentColor`.

- Overlay : `copy`, `check`, `ellipsis`, `x`, `pin`, `pin-off`, `loader-circle`, `eye`, `eye-off`, `clipboard-paste`, `rotate-ccw`, `refresh-cw`, `settings-2`, `info`, `triangle-alert`, `circle-alert`, `circle-check`.
- Actions : `languages` (traduire), `spell-check` (corriger), `briefcase-business` (professionnaliser), `wand` (action personnalisée).
- Réglages : `keyboard` (Actions), `type` (Lecture), `server` (Moteurs), `shield-check` (Confidentialité), `plus`, `trash-2`, `chevron-down`, `power`, `history`.

`pin-off` reste disponible mais l’épingle enfoncée garde `pin`.
