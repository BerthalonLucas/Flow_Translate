# OverlayScenes

Les parcours de l’overlay image par image : Afficher (attente, balayage, ouverture, estompe), Remplacer (attente, coche, disparition, repli si le collage échoue), bande de lecture épinglée, avis seul et verre court posé en bas sans ancre (menu et retour au-dessus).

Page de démonstration : les proportions sont réduites, les durées sont celles du produit (section Parcours).
