# FlowTranslate

A discreet Windows 11 translator: a tiny rounded translucent bubble at the end of selected text, and a bottom capsule for clipboard translation. Tauri 2 / React / Rust client, separate vLLM server.

Implementation in progress. See [specification](docs/SPEC.md) and [bridge contract](docs/BRIDGE.md). The approved images are design references, not screenshots of a working application.

No model weights, credentials or translation history belong in this repository.
